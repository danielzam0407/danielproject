privacy

What this site does with data.

Last updated 26 August 2026

Short version: this is the site of a one-person studio. It has no analytics and sets no cookies. If you never use the chat, the only thing that happens is that a web page loads and the site remembers which language you picked. If you do use the chat, the conversation is stored — that part is below.

What loads when you open the page

Fonts come from Google Fonts. On the home page one stylesheet also comes from unpkg. Loading a file from someone else's server means that server sees your IP address — that is how the web works, and it is true of any site using a font CDN. Neither is used to identify you here.

The page itself is served by Cloudflare Pages, and the chat runs on Cloudflare Workers with its database. Cloudflare keeps its own server logs and acts as a provider working for Daniel, not on its own account.

The site does remember a few small things in your browser so it behaves the way you left it: the language you picked, and — if you open the chat — the id of your conversation and any appearance change you asked the agent for. They stay on your device and are not sent anywhere else.

If you use the chat

The chat sends what you type to a small server run by Daniel, which passes it to DeepSeek, the company whose model writes the replies. Your message and the conversation so far are processed there so an answer can come back.

  • The conversation is stored. Your messages and the agent's replies are saved in a database run by Daniel on Cloudflare, so the thread survives a reload and so he can read what you asked for. He is the only person who can open it.
  • Your IP address is recorded in two places. One is a daily counter, so a single person cannot run the bill up; that one is deleted automatically after 48 hours. The other sits on the conversation itself, so an abusive session can be traced back, and it lasts as long as the conversation does.
  • Conversations do not expire on their own today. They stay until Daniel deletes them. Asking him to delete yours is one message — see below.

If you ask to be put in touch

When the conversation turns into contact — booking a call, opening WhatsApp, or leaving a message — Daniel gets a notification through Telegram with what you asked for and the last few turns of the conversation, so he can answer you properly. If you leave your name and email, those reach him too, and they are kept in the same database as the conversation.

He keeps that the way anyone keeps an email from a potential client. It is not sold, shared, or fed into any advertising system.

Booking a time uses Google Calendar's own booking page, which is covered by Google's privacy policy, not this one.

Calendar access

Daniel uses a private tool that reads and writes his own Google Calendar so he can manage his schedule. It runs on his machine, is used by nobody else, and touches no visitor data. It is mentioned here because Google requires an app using their API to point at a privacy policy.

Children

This site is not aimed at children and does not knowingly collect anything from them.

Asking for your data back

If you have chatted with the agent or written to Daniel and want that deleted, ask him and he will delete it — the conversation, the notification it produced, and anything you left with it.

Write to dani@nervcenter.online, or use the contact page or the chat itself. Say what you want deleted and it gets deleted.

Changes

If this changes, the date at the top changes with it.
