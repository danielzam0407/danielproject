privacy

What this site does with data.

Last updated 24 August 2026

Short version: this is a personal portfolio. It has no analytics, sets no cookies, and stores nothing in your browser. If you never use the chat, the only thing that happens is that a web page loads.

What loads when you open the page

Fonts come from Google Fonts and one stylesheet comes from unpkg. Loading a file from someone else's server means that server sees your IP address — that is how the web works, and it is true of any site using a font CDN. Neither is used to identify you here.

The page itself is served by GitHub Pages, which keeps its own server logs.

If you use the chat

The chat sends what you type to a small server run by Daniel, which passes it to DeepSeek, the company whose model writes the replies. Your message and the conversation so far are processed there so an answer can come back.

  • Your IP address is counted, so one person cannot run the bill up. The counter is a number per address per day and is deleted automatically after 48 hours. It is not linked to your messages.
  • Nothing is stored otherwise. Conversations live in your browser tab while it is open and are gone when you close it.

If you ask to be put in touch

When the conversation turns into contact — booking a call, opening WhatsApp, or leaving a message — Daniel gets a notification with what you asked for and the recent part of the conversation, so he can answer you properly. If you leave your name and email, those reach him too.

He keeps that the way anyone keeps an email from a potential client. It is not sold, shared, or fed into any advertising system.

Booking a time uses Google Calendar's own booking page, which is covered by Google's privacy policy, not this one.

Calendar access

Daniel uses a private tool that reads and writes his own Google Calendar so he can manage his schedule. It runs on his machine, is used by nobody else, and touches no visitor data. It is mentioned here because Google requires an app using their API to point at a privacy policy.

Children

This site is not aimed at children and does not knowingly collect anything from them.

Asking for your data back

If you have written to Daniel and want that deleted, ask him and he will delete it. Since nothing else is stored, there is usually nothing else to delete.

The way to reach him is on the contact section of the site, or through the chat itself.

Changes

If this changes, the date at the top changes with it.
